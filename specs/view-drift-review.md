- **drift** — prose asserts a superseded object as current fact; should repoint

- **ambiguous** — the correction only replaced part of what the cited object said; ambiguous whether to repoint
- **ok** — the citation is deliberately narrating a supersession/correction; no action needed, listed for transparency only
