# The system shall not provide a workspace-level share/ resource SOURCE directory

A workspace has no resource files of its own -- only modules and frameworks do (REQ-resource-file-model). The workspace-level build/<KEY>/share/ output directory still exists as a consolidation point (aggregated from framework-level share/ output via the existing copy-upward mechanism), but there is no corresponding workspace-level share/ SOURCE directory for a developer to populate directly.
