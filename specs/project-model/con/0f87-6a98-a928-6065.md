# Cygwin -- both as the host-side supplier of sh/bmake/tooling for tier-1 MSVC builds, and as the 'Cygwin-native gcc/llvm' tier-1 ABI in its own right -- is scoped to x86/amd64 targets only; it can never produce or represent arm64 win-target output, since the cygwin1.dll runtime it depends on has no arm64 port. arm64 win-target output is reachable only through MSVC (genuinely multi-arch-capable per host VS install) or mingw-w64 cross-compilation (tier 2, via an aarch64-w64-mingw32 sysroot)
