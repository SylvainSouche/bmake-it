Narrows the scope of REQ-packaging-invokes-install-into-distrib-req-v2 and REQ-distrib-dir-for-packaging-staging-req-v2: those describe binary-package targets only (pkg, deb, rpm, msi -- REQ-packaging-per-format-targets-req). make port is a distinct category: it generates the BSD ports-style recipe (a port Makefile, distinfo with source checksums, any needed patch files, and a pkg-plist enumerating installed paths) that points at this project's own source (typically for the ports system's own fetch step), rather than staging or embedding any pre-built binary.
