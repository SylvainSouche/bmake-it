# Toolchain selection on the make command line uses TOOLCHAIN=<gcc|llvm>; unspecified defaults to the current default toolchain, llvm

TOOLCHAIN is a new project-specific variable (no bsd-make-native equivalent exists). Unspecified means the current default toolchain, llvm (REQ-default-toolchain-llvm), matching how TARGET=/TARGET_ARCH= default to the current host when unset. Together with TARGET=<os>, TARGET_ARCH=<arch>, TOOLCHAIN=<gcc|llvm> determine the full compound target key (REQ-target-key-omit-defaults-req).
