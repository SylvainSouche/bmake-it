# The cross-compile sysroot requirement only blocks invocations that can reach a compile step -- not a -V query or a clean

A loud, deliberate error over a missing sysroot exists to protect real builds, not to block every parse of a TARGET/TARGET_ARCH combination that merely resembles a cross build. Scoped via empty(.MAKEFLAGS:M-V*) && !make(clean) around the sysroot-requirement check.
