# Module makefile uses LIBS=lib1 lib2 ... (dev and/or system libraries to link with, link-time only, replacing LINK_WITH). Header include-path resolution is driven solely by the containing framework's PREREQS -- LIBS has no role in header lookup

Supersedes REQ-module-build-macros-req's LINK_WITH design. New macro: LIBS=<lib1> <lib2> ... in a module's makefile, space-delimited, covering both project-internal ('dev') libraries and external system libraries, used exclusively at link time. Header visibility/lookup (REQ-three-level-header-visibility-req) is resolved entirely through the containing framework's PREREQS=... declaration (REQ-framework-prereqs-macro-req) -- a module's LIBS list does not affect which headers are visible to it. PROG=/LIB=/LIB_SHARED= macros and their defaults (REQ-prog-lib-default-to-module-name-req, REQ-lib-shared-is-new-not-reused-req) are unaffected by this change.
