# A dedicated make target builds native OS deployment packages (pkg/deb/rpm/msi/...) from a target's build output; packaging is not part of the default build

Packaging/installation-package creation is invoked explicitly (a separate make target from the default build), and produces native, per-OS package formats rather than (or in addition to) a generic archive: macOS .pkg, Linux .deb and .rpm, Windows-side .msi (scope TBD given Cygwin/WSL-only Windows support), and likely a *BSD ports-style package. Exact target name, per-OS toolchain used to build each package format (e.g. dpkg-deb, rpmbuild, pkgbuild), and whether *BSD ports packaging is in scope are still open follow-ups.
