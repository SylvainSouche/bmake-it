# The build system targets userspace/userland binaries and libraries only; kernel modules/drivers and Darwin/XNU-specific kernel development are out of scope for now

Scopes down the set of build-object-type work: this system builds ordinary userland executables, shared libraries, and static libraries (per REQ-module-is-basic-link-unit and BUILT_OBJECT_TYPE-style object types). Kernel modules/drivers (for FreeBSD, Linux, or any other target) and Darwin/XNU-specific kernel-level development are explicitly out of scope for now, deferred like OpenBSD/NetBSD support and per-Linux-distro handling (REQ-os-label-set-req). Revisit later if kernel-level targets become needed.
