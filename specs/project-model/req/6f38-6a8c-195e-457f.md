# A workspace-level distrib/<KEY>/ directory, parallel to build/<KEY>/ and keyed the same way, is where packaging targets (make port, make pkg, ...) stage an install-prefix-shaped tree before building the actual per-format package artifact from it

Introduces distrib/<KEY>/ at workspace root (same target-key scheme as build/<KEY>/, REQ-target-key-omit-defaults-req), populated by the packaging targets (REQ-packaging-per-format-targets-req) as a staging area mirroring an install-prefix layout (bin/lib/share, matching REQ-build-output-mirrors-prefix-layout). The actual package artifact for each format is built from this staged tree, not directly from build/<KEY>/ and not from an arbitrary temporary directory. Exact mechanism for populating distrib/<KEY>/ (reusing the install machinery with DESTDIR=distrib/<KEY>, or a related-but-distinct copy step) is an open follow-up, not yet nailed down.
