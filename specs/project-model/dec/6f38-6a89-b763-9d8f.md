# Keep the simpler original model for prereq location and header visibility levels, diverging from real mkmk on these two points

Presented with the real mkmk mechanism (dedicated per-framework identity-card special file for prereqs; four-level header visibility: framework Public/Protected/Private + module Local), the user explicitly chose to keep the original, simpler design instead: prereqs stay declared inside the framework-level makefile (REQ-framework-prereqs, unchanged), and header visibility stays two-level -- public include/ and module-local local/include (REQ-framework-header-exposure, unchanged). This is a deliberate divergence from the RADE inspiration, not an oversight, so it's recorded as an explicit rejection (see linked NREQs) rather than left as an open question that might get silently reproposed later.
