# PROG and LIB default to the module's directory name (minus .m suffix) when not explicitly set

User confirmed: if a module's makefile does not set PROG= (executable) or LIB= (library), the output name defaults to the module directory name with its .m suffix stripped -- e.g. module directory hello.m defaults to PROG=hello if unset. This matches the pre-existing REQ-module-dir-naming-convention ('If no explicit library or program name is given...NAME is used') and makes it concrete against the confirmed PROG=/LIB= macros from REQ-module-build-macros-req.
