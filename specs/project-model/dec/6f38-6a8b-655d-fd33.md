# Target OS/arch selection on the make command line reuses real bsd make cross-build variable names, TARGET= and TARGET_ARCH=, rather than inventing new ones

User chose to reuse FreeBSD bsd makes own established cross-build variable convention (TARGET= for the target OS, TARGET_ARCH= for the target architecture -- as used in FreeBSD buildworld-style cross-building) instead of inventing project-specific variable names, consistent with CON-use-bsdmakes general principle of reusing bsd.*.mk infrastructure where it fits. e.g. make TARGET=freebsd TARGET_ARCH=amd64. Toolchain selection (llvm/gcc) is not covered by TARGET=/TARGET_ARCH= alone -- still needs its own variable, open follow-up.
