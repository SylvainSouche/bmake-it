# Toolchain selection on the make command line uses TOOLCHAIN= (e.g. make TOOLCHAIN=gcc); unspecified means the current default (llvm)

User confirmed TOOLCHAIN=<gcc|llvm> as a new project-specific command-line variable (alongside REQ-target-selection-uses-bmake-native-vars-reqs bsd-make-native TARGET=/TARGET_ARCH=), since bsd make has no existing native variable for this. Unspecified means the current default toolchain, llvm (REQ-default-toolchain-llvm) -- consistent with TARGET=/TARGET_ARCH= defaulting to the current host OS/arch when unset.
