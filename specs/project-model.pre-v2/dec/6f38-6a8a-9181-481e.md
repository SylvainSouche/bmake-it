# LIB_SHARED defaults to YES when unset -- a library module is a shared library by default, not a static archive

User confirmed: in a .include <mk.lib.mk> module, if LIB_SHARED is not explicitly set, the default is YES (shared library). A static/archive library requires explicitly setting LIB_SHARED=NO (or similar) -- exact opposite-value macro/syntax not yet nailed down but the default behavior itself is now confirmed.
