# Binary/library output naming must support embedding a version number in the filename, following standard *nix conventions (e.g. soname-style versioning)

New requirement raised directly by the user while reviewing output naming: file and makefile naming must support version numbers embedded in the output filename, as has become standard on *nix -- e.g. the libfoo.so.MAJOR.MINOR.PATCH / libfoo.MAJOR.dylib soname-style conventions used by shared libraries on Linux/BSD/macOS. Extends REQ-output-naming-os-conventions, which did not previously address versioning at all. Exact mechanism (a new module makefile macro like VERSION= or LIB_VERSION=, symlink chain generation, SONAME handling) not yet specified -- open follow-up.
