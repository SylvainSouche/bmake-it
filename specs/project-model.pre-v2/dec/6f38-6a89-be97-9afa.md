# Canonical <os> labels for the target key: macos, win, freebsd, linux; openbsd/netbsd and per-Linux-distro handling deferred to later

User settled the <os> label spelling for the target key (REQ-target-key-string-format-req): macos (not macosx/darwin), win (covering the Cygwin/WSL-based Windows support from REQ-windows-hosts-cygwin-wsl -- single label for now, no cygwin-vs-wsl distinction yet), freebsd, and linux. OpenBSD and NetBSD (implied by CON-cross-platform-targets' generic *BSD wording) are deferred -- to be addressed later, not phase 1. Similarly, whether/how Linux distro differences need their own labels (vs. a single generic linux label) is deferred.
