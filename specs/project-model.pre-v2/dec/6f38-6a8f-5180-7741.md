# make help lists every valid make target and every valid variable (with valid values) applicable at the current level (module/framework/workspace), self-documented by each role-specific mk.*.mk file

New target: make help. Since bsd make has no built-in help system, each role-specific include file (mk.workspace.mk, mk.framework.mk, mk.prog.mk, mk.lib.mk, mk.toolchain.<name>.mk -- REQ-uniform-makefile-filename-req) is responsible for documenting its own targets and variables and contributing to a help: target that prints them. Run at any level, make help shows what's applicable there: at module level, PROG=/LIB=/LIBS=/LIB_SHARED=/INCL=/SHLIB_MAJOR=/SHLIB_MINOR= plus the reused bsd-native flags (CFLAGS/CXXFLAGS/LDFLAGS/YFLAGS/LFLAGS/DEBUG_FLAGS); at framework level, PREREQS=; at workspace level, PARENT_WS=; CLI-level target-selection variables (TARGET=/TARGET_ARCH=/TOOLCHAIN=) and all make targets (all/clean/install/run/help/pkg/deb/rpm/msi/port/add-prereq/add-parent) everywhere. Each entry includes a description and, where applicable, the set of valid values (e.g. LIB_SHARED=YES|NO, TOOLCHAIN=gcc|llvm).
