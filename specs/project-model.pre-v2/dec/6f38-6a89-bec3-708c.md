# Kernel-level development (kernel modules/drivers) and Darwin/XNU-specific development are explicitly deferred, not in scope for now

User flagged, in the context of settling target OS labels, that kernel-level development (kernel modules, drivers) and Darwin-specific development (building against XNU/Darwin internals rather than the userspace macOS environment) are being deferred -- "we will see later" -- consistent with the treatment of OpenBSD/NetBSD and per-Linux-distro scope (REQ-os-label-set-req). The build system, for now, targets ordinary userspace/userland binaries and libraries only.
