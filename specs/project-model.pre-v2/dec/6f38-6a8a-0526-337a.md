# Module makefile uses PROG= (executable name, with mk.prog.mk), or LIB= plus optional LIB_SHARED=YES (library name/kind, with mk.lib.mk); LINK_WITH= lists libraries used for both header access and linking

User specified concrete macro names for a module's makefile, refining REQ-module-makefile-fields and REQ-uniform-makefile-filename-req's mk.prog.mk/mk.lib.mk split: for an executable module (.include <mk.prog.mk>), PROG=PROGRAMNAME sets the output name. For a library module (.include <mk.lib.mk>), LIB=LIBRARYNAME sets the base library name, and LIB_SHARED=YES switches it to a shared library (its absence presumably means static/archive -- default not yet explicitly confirmed). LINK_WITH=lib1 lib2 ... is a space-delimited list of libraries this module uses, and is dual-purpose: it drives both compile-time header visibility (REQ-three-level-header-visibility-req) and link-time linking against those libraries -- mirroring real mkmk's LINK_WITH macro (see OBS-mkmk-module-buildfile-macros) but scoped to this project's own model.
