# A workspace does not carry its own share/ resources; only modules and frameworks do

Directly answers the open question in the directory-layout spec draft: a workspace only contains frameworks -- confirming REQ-workspace-is-set-of-frameworks at face value. No workspace-level share/ source directory exists; the workspace-level build/<KEY>/share/ seen in the draft spec is purely a consolidation point aggregated from framework-level resources, not something with its own source.
