# Copy-up collisions are diff-aware: identical-content collisions are silent, differing-content collisions warn but still overwrite (build proceeds), EXCEPT the deliberate share/ specificity overlay (platform-specific legitimately overwriting generic) which is expected behavior and never warns

User specified a nuanced, diff-aware collision policy for copy-up (module to framework to workspace, REQ-aggregation-step-copies-outputs) rather than a blanket error or blanket silent-overwrite: (1) if the two colliding files are byte-identical, no message is emitted, the copy proceeds silently (harmless, doesnt matter which wins since theyre the same); (2) if the two colliding files DIFFER and it is a genuine, unexpected collision (e.g. two modules or frameworks independently producing a same-named artifact), a WARNING is emitted but the build still proceeds, overwriting rather than hard-stopping; (3) explicit exception: when the differing content is due to the DELIBERATE share/ specificity overlay (REQ-share-overlay-copy-order -- a more-specific os_arch or os-level file intentionally overwriting a less-specific common-level file with different content), this is expected, by-design behavior, not a collision -- no warning is emitted in this case, regardless of the content differing.
