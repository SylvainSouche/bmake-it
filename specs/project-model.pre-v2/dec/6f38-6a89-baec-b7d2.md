# Framework/workspace-level build/$OS_ARCH/bin,lib is populated by copying module build outputs, as a distinct build step

User chose plain copy over symlinks or direct-build-in-place: after modules are compiled and linked (into their own module-level build/$OS_ARCH/), a second, distinct build step copies everything relevant up to the top level (framework and/or workspace build/$OS_ARCH/bin,lib). This is simpler and more portable across the target platforms (symlinks behave differently or are unavailable on some Windows-adjacent setups) than symlink-based consolidation, at the cost of some duplication on disk.
