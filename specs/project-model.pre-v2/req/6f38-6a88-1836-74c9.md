# A workspace may declare an ordered list of parent workspaces; the build looks up missing elements in parent workspaces in declaration order

A workspace can have a set of 'parent' workspaces. When the build needs an element (framework/module/artifact) not found in the current workspace, it looks it up in the listed parent workspaces, trying them in the order they were declared. Open question: exact declaration syntax/file for the parent list is not yet specified. CONFIRMED (2026-08-22): this is the ONLY prerequisite-access mechanism -- purely dynamic search, no physical-copy mode, no dedicated setup command (see DEC-6f38-6a89-bd4b-3e07 and NREQ-6f38-6a89-bd4b-c4ce).
