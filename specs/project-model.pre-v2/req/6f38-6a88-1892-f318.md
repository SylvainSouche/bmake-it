# A module may carry resource files (non-source data) which are staged into the build output alongside the binary

<!-- Free-text description / rationale goes here. -->
A module can include resource files: non-source data it ships (icons,
config files, plists, etc.), distinct from compiled source files. These
are staged into the build output alongside the produced binary or
library, so they're available at runtime next to the artifact.

Open sub-questions (not yet decided, do not assume): where resource files
live within the module directory (a dedicated directory analogous to
`src`?), the exact staging path under the OS_ARCH output, whether any
processing/transformation happens versus verbatim copy, and whether
frameworks (as opposed to modules) can also carry resources.
