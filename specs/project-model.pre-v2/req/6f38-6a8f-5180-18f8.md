# make run PROGRAM=<name> ARGS=<args>, invoked at workspace level, sets the platform-appropriate dynamic-library search path (LD_LIBRARY_PATH/DYLD_LIBRARY_PATH/etc.) to include workspace build/<KEY>/lib/, then executes build/<KEY>/bin/<PROGRAM> with the given arguments

PROGRAM=<name> names an executable already present in the current targets workspace build/<KEY>/bin/ (does not implicitly build it first -- consistent with REQ-install-requires-prebuilt-target-req's precedent of not auto-triggering a build). ARGS=<args> is passed through to the program verbatim. Before execution, the appropriate per-OS dynamic-library search-path environment variable is set to include workspace build/<KEY>/lib/ (so shared libraries built by any framework in this workspace are found without needing a real install step) -- exact variable per REQ-os-label-set-req's os labels: LD_LIBRARY_PATH (freebsd, linux), DYLD_LIBRARY_PATH (macos), PATH-inclusion (win). Exact mechanism for locating/setting this (a small wrapper script generated by mk.workspace.mk, vs. inline make recipe logic) is an open follow-up for implementation.
