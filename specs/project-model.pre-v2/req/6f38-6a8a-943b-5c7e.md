# Setting LIB_SHARED=NO in a library module's makefile builds a static/archive library instead of the default shared library

Closes the open follow-up on REQ-lib-shared-defaults-yes-req: LIB_SHARED=NO is the explicit opt-out syntax for a static/archive library, LIB_SHARED=YES (or unset, the default) builds a shared library.
