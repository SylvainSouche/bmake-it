# $OS_ARCH identifies OS+architecture only; debug/release build variant does not get its own directory in the build tree

$OS_ARCH (used throughout the build/$OS_ARCH/ tree, see REQ-build-output-tree-structure) encodes only operating system and CPU architecture (e.g. linux-x86_64, macosx-arm64), never build variant. Debug and release/optimized builds of the same target share the same build/$OS_ARCH/ subtree and therefore overwrite each other -- there is no side-by-side coexistence of variants the way there is for different OS/arch targets. Resolves the "variant" open follow-up on REQ-build-output-tree-structure.
