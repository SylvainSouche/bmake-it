# Packaging targets stage distrib/KEY by invoking install with DESTDIR=distrib/KEY, reusing the install/DESTDIR/PREFIX mechanism rather than a separate copy step

Closes the open mechanism follow-up on REQ-distrib-dir-for-packaging-staging-req: each packaging target (REQ-packaging-per-format-targets-req) begins by running the equivalent of install DESTDIR=distrib/KEY (REQ-destdir-prefix-confirmed-req), reusing the same staging mechanism as a manual make install rather than inventing a separate copy step. The per-format package artifact (.pkg, port, .deb, etc.) is then built from that staged distrib/KEY tree.
