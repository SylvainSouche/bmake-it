# make clean removes only the current or explicitly-selected target build/<KEY>/ subtree (via TARGET=/TARGET_ARCH=/TOOLCHAIN=); TARGET=all clears build/ output for every target at once

make clean respects the same target-selection variables as a normal build (REQ-target-selection-uses-bmake-native-vars-req, REQ-toolchain-cli-variable-req): with no variables set, it cleans the current/default targets build/<KEY>/ subtree; with TARGET=/TARGET_ARCH=/TOOLCHAIN= set, it cleans that specific targets subtree; with the special value TARGET=all, it removes build/ output for every target present, i.e. the whole build/ tree. This preserves other coexisting targets build output by default, matching the point of keying build/ by target (REQ-build-output-tree-structure).
