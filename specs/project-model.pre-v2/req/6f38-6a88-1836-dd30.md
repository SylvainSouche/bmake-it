# A framework exposes headers to the outside via its include directory, and to its own modules via a local/include directory

Two visibility levels for a framework's headers: (1) public -- exposed in the framework's `include` directory, visible to consumers outside the framework (i.e. other frameworks that declare it as a prereq); (2) framework-internal -- exposed in `local/include`, visible only to the framework's own modules, not to external consumers.
