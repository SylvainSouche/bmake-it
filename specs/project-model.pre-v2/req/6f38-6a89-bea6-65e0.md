# The target key <os> component uses one of: macos, win, freebsd, linux; openbsd, netbsd, and Linux-distro-specific labels are deferred, not decided for phase 1

Finalizes the <os> label spelling left open by REQ-target-key-string-format-req. Canonical values: macos, win (Cygwin/WSL, undifferentiated for now), freebsd, linux. Phase 1 (REQ-phase1-concrete-targets) only exercises macos and freebsd. Deferred, not yet decided: whether OpenBSD/NetBSD get their own os labels or share a generic bsd-family label, and whether Linux needs per-distro os labels (e.g. for differing package-manager targets in the packaging step) or a single generic linux label suffices.
