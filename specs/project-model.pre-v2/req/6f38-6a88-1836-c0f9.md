# The default C/C++ compiler is LLVM/clang; the legacy OS-native compiler (e.g. system gcc) may be used as an alternative

For C and C++ compilation, the build system can use either the legacy OS-provided compiler (e.g. system gcc) or LLVM. LLVM is the default toolchain when nothing else is specified. Open question: exact mechanism/variable to opt into the legacy compiler is not yet specified.
