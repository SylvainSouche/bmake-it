# The build directory key (used throughout build/<KEY>/ at module, framework, and workspace levels) is a compound of OS, architecture, AND toolchain -- not OS+arch alone -- so different toolchains for the same OS/arch coexist in the same source tree

Refines REQ-build-output-tree-structure and REQ-variant-out-of-scope-for-dirtree: the directory key referred to as $OS_ARCH in earlier requirements is actually a three-part target identifier: operating system, CPU architecture, and toolchain (e.g. gcc or llvm). Two builds of the same OS/arch with different toolchains produce separate, independently addressable build/<KEY>/ subtrees at every level (module obj/, framework and workspace bin/lib/). Build variant (debug/release) is still explicitly excluded from this key -- only OS, arch, and toolchain participate. Exact string format for the compound key is an open follow-up.
