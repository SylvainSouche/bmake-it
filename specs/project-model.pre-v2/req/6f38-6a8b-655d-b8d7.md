# Non-default OS/architecture target selection on the make command line uses TARGET= and TARGET_ARCH=, matching real bsd make/FreeBSD cross-build variable naming; default (unset) means the host OS/arch

Target selection reuses bsd makes own established variable names rather than inventing new ones: TARGET=<os> and TARGET_ARCH=<arch> on the make command line, e.g. make TARGET=freebsd TARGET_ARCH=amd64. When unset, defaults to the host OS/arch (REQ-default-build-host-os-arch). These two variables determine the <os>-<arch> portion of the compound target key (REQ-target-key-omit-defaults-req). Toolchain selection (llvm/gcc) is a separate, not-yet-named variable -- open follow-up.
