# Toolchain selection on the make command line uses TOOLCHAIN=<gcc|llvm>; unspecified defaults to the current default toolchain, llvm

Completes the command-line target-selection story alongside REQ-target-selection-uses-bmake-native-vars-req: TARGET=<os>, TARGET_ARCH=<arch>, TOOLCHAIN=<gcc|llvm> together determine the full compound target key (REQ-target-key-omit-defaults-req). TOOLCHAIN is a new project-specific variable (no bsd-make-native equivalent exists). Unspecified means the current default toolchain, llvm (REQ-default-toolchain-llvm), matching how TARGET=/TARGET_ARCH= default to the current host when unset.
