# Module-level build/<KEY>/ contains obj/ (intermediate objects), bin/ or lib/ (the module's own linked artifact, matching whether it's a PROG or LIB module), and share/ (staged module resources) -- same subdirectory names as framework/workspace level

Confirms and closes the open naming question in REQ-build-output-tree-structure and spec/directory-layout.md: module/build/<KEY>/ holds obj/ for intermediates, bin/ (PROG modules) or lib/ (LIB modules) for that module's own linked artifact prior to copy-up (REQ-aggregation-step-copies-outputs), and share/ for staged module-level resources prior to copy-up (REQ-resource-file-model). Naming is consistent with framework/workspace level bin/lib/share.
