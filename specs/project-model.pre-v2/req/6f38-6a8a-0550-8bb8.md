# Module output naming supports an embedded version number following standard *nix conventions for versioned shared libraries (e.g. soname-style MAJOR.MINOR.PATCH suffixing)

Extends REQ-output-naming-os-conventions: in addition to the base NAME/libNAME naming already decided, the build system must support attaching a version number to a module's output filename, following standard *nix shared-library versioning conventions (e.g. libfoo.so.1.2.3 with libfoo.so and libfoo.so.1 as symlinks, or libfoo.1.dylib on macOS). Exact mechanism -- new module makefile macro(s) to declare the version, whether/how symlink chains get generated, SONAME handling per platform -- is not yet specified; this REQ records the requirement itself, not yet the design.
