# Module directory name case-sensitivity is whatever the host filesystem provides; the build system does not itself enforce or normalize case

Module directory names (NAME.m, per REQ-module-dir-naming-convention) are treated with whatever case-sensitivity the underlying filesystem provides -- distinct names on a case-sensitive filesystem, potentially colliding on a case-insensitive one (e.g. macOS's typical default). The build system does not add its own case-normalization or collision detection layer on top of the filesystem's own behavior.
