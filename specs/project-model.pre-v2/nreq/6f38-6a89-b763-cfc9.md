# The system shall not require a dedicated per-framework identity-card special file for declaring prereqs

Rejected alternative: a separate special file per framework (as in real mkmk's IdentityCard.h) dedicated solely to declaring prerequisite frameworks. Prereqs are instead declared inside the framework-level makefile, per REQ-framework-prereqs.
