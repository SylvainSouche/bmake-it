# The system shall not implement the four-level (Public/Protected/Private/Local) header visibility hierarchy

Rejected alternative: real mkmk's four-tier header visibility model (framework-level Public, Protected, Private directories, plus module-level Local), with build-time enforcement of cross-level and cross-framework include rules. The system instead keeps a two-level model: one public include/ directory per framework, one local/include/ directory visible only to the framework's own modules, per REQ-framework-header-exposure.
