# PREREQS= is now a MANDATORY variable in every framework makefile, even when the framework has no prerequisites (PREREQS= with nothing after it)

New requirement raised while resolving workspace-level framework auto-discovery: every framework makefile must declare PREREQS= explicitly, even if empty. This upgrades PREREQS from an ordinary optional-if-no-deps macro (as REQ-framework-prereqs-macro-req originally implied) to a mandatory one, because its presence now doubles as the discovery signal that distinguishes a framework-level makefile from a module-level or workspace-level one during workspace scanning (REQ-modules-and-frameworks-auto-discovered-req).
