# UEFI for the amd64 guests: BOOT uefi-amd64 boots q35 with QEMU's edk2-x86_64-code.fd and a copy of edk2-i386-vars.fd; Debian and FreeBSD then use the arm64 console script (FreeBSD) or none (Debian, cloud-init). NetBSD's amd64 EFI loader still gives the kernel the video console, so NetBSD amd64 keeps console-netbsd-bios (consdev com0, kept in boot.cfg) under UEFI too; bios-amd64 and the -bios console scripts remain for images that cannot boot UEFI
