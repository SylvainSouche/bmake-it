# Doxygen's own standard project-identity fields (PROJECT_NAME/PROJECT_NUMBER/PROJECT_BRIEF/PROJECT_LOGO, HTML_FOOTER for a license notice) are populated by auto-detecting conventional workspace-root files -- VERSION, LICENSE, docs/logo.{png,svg} -- defaulting to the framework/workspace directory name for PROJECT_NAME when no override is given. No bespoke override mechanism is needed: a workspace or framework's own pre.mk (per local-mk-hook-files-and-cascade-order-req) already runs before this auto-detection, so DOC_PROJECT_NAME=/DOC_PROJECT_VERSION=/DOC_PROJECT_BRIEF=/DOC_LOGO= set there are respected

Implemented ahead of this spec entry, then verified empirically: workspace-level pre.mk overrides the workspace default; framework-level pre.mk overrides just that framework, without leaking to siblings; unset values cascade from workspace to framework correctly.
