# Resource file = non-source data a module ships, staged into build output alongside the binary

<!-- Free-text description / rationale goes here. -->
Confirmed via clarifying question: a "resource file" is non-source data a
module ships (icons, configs, plists, and similar), which the build stages
into the build output alongside the produced binary/library.

Still open, deliberately not assumed: (1) what directory holds resource
files within a module (analogous to `src` for sources -- candidate name
not yet chosen), (2) exact staging location under `obj/<OS_ARCH>/` (or
elsewhere) relative to the binary, (3) whether resources are copied
verbatim or can go through a processing step (e.g. plist compilation on
macOS), (4) whether frameworks (not just modules) can carry resources.
