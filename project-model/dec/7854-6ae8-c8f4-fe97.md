# Delay loading: DELAYLOAD=yes|no on the library (default no, written to lib<name>.delayload with its DLL name and whether it exports data), DELAYLOAD.<lib>=yes|no on a program or shared library linking it. MSVC and lld by DLL name, GNU ld by a delay-import library from the DLL's .def, nothing elsewhere (a library's default has no effect, a consumer's yes prints a note). A DLL known to export data is refused; an imported DLL's name comes from its import library, and it is refused under GNU ld
