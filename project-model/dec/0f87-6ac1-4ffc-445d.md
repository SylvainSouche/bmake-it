# bmake run PROGRAM=<name> runs ANY program with the build environment set, not only one found in the current workspace's bin: PROGRAM is resolved through the environment's own PATH, so a built program, 'sh' (an interactive subshell with that environment), 'env' or any other command all work, and no separate shell/env target is added. Resolution order: the workspace bin, then each PARENT_WS bin, then the caller's PATH, so a project binary shadows a system one of the same name (as with DS mkmk -run). Rejected: a dedicated 'bmake shell'/'bmake env' target
