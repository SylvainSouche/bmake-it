# Administrative configuration has two sets: a LOCAL WORKING SET (the configuration makefile and its cache, edited and exercised by the administrator with the administrative targets) and a DEPLOYED CONFIGURATION SET. The deployed set is what the Bmake It machinery reads: a project build reads only the deployed set, never the working makefile. This resolves how a build sees configuration without loading the administrative targets. The proposals in chapter 05 (site/user configuration levels, declaration-hash naming, tiered cache, lockfile, administrative target names) are validated; their listed open sub-questions stay open
