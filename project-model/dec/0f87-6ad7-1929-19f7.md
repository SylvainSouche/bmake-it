# Test-VM disks are layered: a pristine decompressed base, a provisioned layer (ssh key, sshd, packages) over it, and a disposable per-run overlay over that; resetting a VM deletes only the overlay. Where the cache lives is configurable (BMK_CACHE, default ~/.bmk-cache) and runtime sockets and pidfiles live in a separate local directory (BMK_RUN), because an external exFAT drive cannot hold unix sockets
