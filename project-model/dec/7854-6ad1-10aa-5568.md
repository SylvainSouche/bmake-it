# One pkg-config per build, chosen in mk.common.mk and used by IMPORT=pkg: and REQUIRES=: PKG_CONFIG= if set; for mingw-w64 output <triple>-pkg-config, else (with BMK_MINGW_SYSROOT) plain pkg-config limited to that sysroot's lib/pkgconfig, else an error -- never the host's .pc files; otherwise pkg-config. The resolution cache key adds OS_ARCH (ABI and toolchain), CC and the pkg-config used; a hit records the resolved .pc file (pcfiledir/<name>.pc) and its mtime and is discarded when that file is gone or changed (bmake :mtime, no subprocess). The cross branch uses BMK_MINGW_SYSROOT for win.
