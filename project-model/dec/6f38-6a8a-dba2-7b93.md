# Framework modules (*.m subdirectories) and workspace frameworks (any immediate subdirectory) are auto-discovered by scanning, not explicitly listed in the parent makefile -- consistent with src/ source auto-discovery

User confirmed auto-discovery over explicit SUBDIR=-style listing, for both levels: a frameworks modules are found by scanning for *.m-suffixed immediate subdirectories (REQ-module-dir-naming-convention already gives this a reliable naming signal); a workspaces frameworks are found by scanning immediate subdirectories. This matches the auto-discovery philosophy already used for module sources (REQ-module-src-auto-discovery) -- no explicit module or framework list needs to be maintained by hand.
