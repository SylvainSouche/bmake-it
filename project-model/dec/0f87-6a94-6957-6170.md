# Objects whose refines edge pointed at an ancestor later superseded are re-pointed to that ancestor's live successor

The v1->v2 migration correctly marked several old requirements as superseded, but confirmed objects that refined them were left refining a dead object -- refinement cannot express 'this ancestor was replaced,' only supersession can. model.py check --strict now reports these as REFINES-DEAD. Each flagged object is superseded by an otherwise-identical replacement whose refines edges are re-pointed at the live successor, using model.py supersede so the correction is itself a recorded, DEC-backed change rather than a silent edit.
