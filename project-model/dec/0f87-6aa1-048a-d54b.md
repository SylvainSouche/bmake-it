# All execution paths must fail gracefully, with explanation, when run with invalid options or in an inappropriate location

User: 'All execution path must fail gracefully and with explanation when run with invalid option or in inappropriate location.' Recorded as a system-wide design principle: every make target and macro validates its own inputs and directory-level context, failing with a clear, named diagnostic rather than a raw make/tool error or silent misbehavior. Explicitly linked at the time to the one instance already designed in detail (link-time-not-yet-built-guard), now treated as the template for how this gets done elsewhere, and to the help-target design, since a graceful-failure message can point back to make help for the full list of valid values rather than repeating everything inline. Named targets/macros expected to need this: TOOLCHAIN=, LIB_SHARED=, add-prereq/add-parent, make run, make order.
