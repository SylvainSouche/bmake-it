# Module makefile uses INCL= to list which generated headers are promoted to public (copied up to framework build/<KEY>/include/)

Resolves the open declaration-macro follow-up from REQ-generated-headers-in-build-tree-req: a module names its promoted-public generated headers via INCL=<header1> <header2> ... in its makefile. Listed headers are copied from module/build/<KEY>/include/ up to framework/build/<KEY>/include/ on module build; unlisted generated headers stay module-private.
