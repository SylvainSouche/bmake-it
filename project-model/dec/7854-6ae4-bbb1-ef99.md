# The ATF Bmake It carries keeps ATF's upstream source tree as released (contrib/atf-0.23) and is built without ATF's autotools by scripts/atf-build.sh (Windows layer, or POSIX config probes), not yet by a Bmake It module description

Keeping the tree as released makes an upgrade a drop-in plus a matrix run, and keeps it comparable with upstream; a src/ module layout would make it a hand-kept fork. Move the build to a Bmake It description once Bmake It can build an out-of-tree source list with per-file flags (worth having for vendored third-party code anyway), or when the port grows (process support for atf_check, atf_utils_fork via CreateProcess) and the file list and flags stop being trivial.
