# make clean removes only the current (or explicitly specified via TARGET=/TARGET_ARCH=/TOOLCHAIN=) targets build/<KEY>/ subtree; TARGET=all is a special value that wipes build/ output for every target at once

User confirmed clean is scoped by the same TARGET=/TARGET_ARCH=/TOOLCHAIN= variables used for building (REQ-target-selection-uses-bmake-native-vars-req, REQ-toolchain-cli-variable-req): make clean (optionally with those variables set to a specific or the current target) removes just that targets build/<KEY>/ subtree, leaving every other coexisting targets output untouched -- consistent with the whole point of the target-keyed build/ tree (REQ-build-output-tree-structure). TARGET=all is reserved as a special value meaning every target: make clean TARGET=all wipes the entire build/ tree regardless of what individual targets exist.
