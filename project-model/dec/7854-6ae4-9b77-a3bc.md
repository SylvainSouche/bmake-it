# Native Windows test programs link an ATF built by Bmake It from ATF's own released sources (0.23, unmodified) plus a Windows compatibility layer, and are run by the Cygwin Kyua the Windows host already has; ATF features not ported yet fail the test case naming the feature

Rejected: switching to gtest (rewrites every test, C tests need C++, still a dependency); a hand-written ATF-alike (drifts from real ATF). Kyua is not ported: its system layer is POSIX (fork, process groups, getpwnam), but the Cygwin build runs native .exe test programs. Rule: a test that builds and passes against this ATF builds and passes unchanged against real ATF and Kyua -- the POSIX cells check it. First scope: test case definition, checks, skips, expected failures, atf_utils file and grep helpers; atf_utils_fork/wait, atf_check and atf-sh are POSIX-only for now.
