# Cross-compilation implemented via clang --target=/--sysroot=, one sysroot per target OS, never bundled

clang is one binary targeting many platforms via --target/--sysroot; gcc would need a dedicated cross-built binary per target, so cross support lives only in mk.toolchain.llvm.mk (TOOLCHAIN=gcc has none). Sysroots are never bundled or fetched by the project -- each has its own license/distribution terms and must be staged locally by the user (FreeBSD's base.txz is fully open; a Linux sysroot is just files off a real system; the macOS SDK is Apple-licensed for building on/for Apple platforms only).
