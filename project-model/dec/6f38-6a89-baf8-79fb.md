# Build variant (debug/release) is not encoded in $OS_ARCH; it is a separate concern

User confirmed: $OS_ARCH identifies operating system and architecture only. Build variant (debug vs. release/optimized) is a separate axis and does not get its own directory in the build/$OS_ARCH/ tree. Consequence (consistent with how real mkmk handles its -g/-dev flags, per OBS-mkmk-command-phases-and-cli): switching variant for a target and rebuilding overwrites that target's existing obj/bin/lib in place rather than coexisting side by side. A clean or forced rebuild is needed to switch variants cleanly.
