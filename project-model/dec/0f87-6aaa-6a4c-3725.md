# REPORT=yes and FAIL_FAST=yes are two independent flags, not one: REPORT=yes controls only whether the workspace-level dashboard gets built (build-report/ or test-report/) from whatever a run left behind; FAIL_FAST=yes controls only whether one module's/framework's failure stops a workspace/framework all/test run before every other one gets attempted. Default for both is the continue-past-failure, no-dashboard behavior -- matching how test already behaved before REPORT= existed -- not fail-fast-by-default
