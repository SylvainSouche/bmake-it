# make run PROGRAM=<name> ARGS=<args> builds a correct runtime environment (dynamic library search path set appropriately per-OS: LD_LIBRARY_PATH on Linux/FreeBSD, DYLD_LIBRARY_PATH on macOS) and executes the named built program with the given arguments, mirroring real mkmk's mkrun command

New target, run at workspace level: make run PROGRAM=<name> ARGS='<args>'. Constructs the runtime environment a freshly-built program needs to find its shared libraries -- since those live under workspace build/<KEY>/lib/ (REQ-aggregation-step-copies-outputs), not a system-wide location -- by setting the platform-appropriate dynamic-library search path variable (LD_LIBRARY_PATH on Linux/FreeBSD, DYLD_LIBRARY_PATH on macOS, PATH-inclusion on win/Cygwin/WSL) to include that directory, then executes workspace build/<KEY>/bin/<PROGRAM> <ARGS>. This mirrors real mkmk's mkrun command (which initializes PATH/LIBPATH/SHLIB_PATH/LD_LIBRARY_PATH per-platform before running a built program) -- adapted to this project's own build/<KEY>/ layout rather than mkmk's own runtime-view mechanism.
