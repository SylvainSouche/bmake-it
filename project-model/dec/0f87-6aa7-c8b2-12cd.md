# For a real production build/test operational environment, the local VM-provisioning mechanism can be replaced by a grid infrastructure: a pool of identified, dedicated virtual or physical machines usable for build or test, instead of provisioning VMs on demand

Distinct from the caching/layering mechanism (version-freshness-caching-policy) -- grid machines are pre-existing and persistent, not ephemeral VMs rebuilt from cached layers, so that policy does not directly apply here.
