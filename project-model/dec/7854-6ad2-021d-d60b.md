# A *.m or *.tst directory with no makefile whose entries are all build output (build, distrib, work, distfiles, .depend, .gen-*.mk) is a leftover, not a module: discovery skips it with a warning naming it and saying bmake clean removes it, and the framework's clean deletes it. A directory with no makefile holding anything else stays an error for discovery and is never touched by clean.
