# Build/test environments are managed at three levels. USER: the user declares a distro and packages and the tooling downloads/builds the matching environment locally. COMPUTER OR TEAM (in between): an administrator builds the environment locally once, or copies it from another machine's cache, and stores it locally for every user of that machine. ENTERPRISE: builds are configured against a managed OS/software baseline -- either a preset OS and toolchain, or one built by the same tooling, whose advantage is a fully reproducible process. The first implementation target is the COMPUTER/TEAM level: build and store locally for all users.
