# Test writing and orchestration is built on ATF (atf-c/atf-c++ for compiled test cases, atf-sh for shell-script test cases) and Kyua (the runner), reusing the proven bsd.test.mk declarative model natively within Bmake It's own mk.*.mk -- not a CMake/CTest dependency, since Bmake It is itself a CMake alternative and depending on CTest would be self-contradictory

Cross-platform availability on non-BSD hosts (Linux/macOS/Windows) is unverified -- ATF/Kyua is native and well-packaged on the BSDs (FreeBSD and NetBSD both use it for their own base-system test suites), but far less universally available elsewhere than gtest/Catch2. Adopted on a try-first, empirical basis: use ATF/Kyua, and if/when actual cross-platform testing reveals it doesn't work well outside the BSD family, reassess at that point rather than pre-designing around the gap now.
