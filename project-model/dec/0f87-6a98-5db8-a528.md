# Scope the cross-compile sysroot requirement check to invocations that can actually reach a compile step, using bmake's own make(clean) predicate and a .MAKEFLAGS:M-V* check

Confirmed empirically: bmake's make(target) builtin correctly distinguishes a clean invocation from a normal build, and .MAKEFLAGS:M-V* correctly detects a -V query, in both a bare 'bmake -V X' form and when combined with an explicit target. Both checks run at parse time, same as the requirement check itself, so no new parse-order issue is introduced.
