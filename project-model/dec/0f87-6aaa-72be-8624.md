# Per-run logs/reports are identified by RUN_ID=, defaulting to a timestamp+PID (date +%Y%m%d-%H%M%S-$$, collision-safe without needing GNU-only date extensions like %N), overridable so an external CI can pass its own build number or commit SHA instead -- keeps Bmake It's own VCS-blindness (ci-integration-scope-boundary) rather than hardcoding git awareness. Computed once at the top of a recursive run and forwarded down like SANITIZE=/REPORT=/FAIL_FAST=, so every module/framework touched by one run shares the same RUN_ID. A runs/latest symlink is kept pointing at the newest run, since a LAN site needs a stable link, not a timestamp to guess
