# make install requires the current (or selected) target to have already been built; it does not trigger a build itself. Cross-install onto a different filesystem/mount is deferred for later

User clarified two things about make install (REQ-install-target-exists-req, REQ-destdir-prefix-confirmed-req): (1) it can only be invoked once the current (or TARGET=/TARGET_ARCH=/TOOLCHAIN=-selected) targets build/<KEY>/ output already exists -- it does not implicitly trigger a build first, unlike some install targets that depend on all as a prerequisite; (2) installing across filesystems (e.g. installing a build output onto a different mounted filesystem, or some other cross-filesystem scenario the user has in mind but has not fully specified) is deferred, joining the standing list of later items.
