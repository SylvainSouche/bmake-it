# glibc is the implicit default libc for Linux targets; linux-<arch> alone means glibc, musl is always shown explicitly

User confirmed glibc as the default libc for Linux, consistent with REQ-target-key-omit-defaults-req: linux-arm64 alone means glibc (the common/mainstream case), while musl must always be spelled out explicitly, e.g. linux-arm64-musl. Note Linux itself is still not part of REQ-phase1-concrete-targets and per-distro Linux handling remains deferred (REQ-os-label-set-req) -- this only settles the glibc/musl default question raised in OBS-linux-libc-choice-parallels-win-abi, for whenever Linux support is actually built.
