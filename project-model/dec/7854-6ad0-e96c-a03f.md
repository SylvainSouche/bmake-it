# On a Cygwin host, ABI=mingw selects mingw-w64 output for the host's own arch: TOOLCHAIN=gcc uses <triple>-gcc/-g++/-ar/-ranlib; TOOLCHAIN=llvm uses clang --target=<triple>, with --sysroot only when BMK_MINGW_SYSROOT is set and otherwise clang's own detection of the installed mingw-w64 gcc (an explicit Cygwin sys-root was tested to break C++ and libgcc), linking with lld when installed, else mingw's GNU ld. The same tool choice applies to every mingw-w64 build (tier 2 included). The win ABI slot is read from the compiler's own -dumpmachine (cygwin|cygnus -> cygwin, mingw32|windows-gnu -> mingw, windows-msvc -> msvc; TOOLCHAIN=msvc is msvc), replacing the rule-based derivation.
