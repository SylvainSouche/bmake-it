# Local customization uses six conventional, specifically-looked-for filenames (pre.mk, local.mk, pre.${TOOLCHAIN}.mk, local.${TOOLCHAIN}.mk, pre.${TARGET}.mk, local.${TARGET}.mk -- pre.* included before a role file's own defaults are computed, local.* after), mirroring the existing mk.toolchain.${TOOLCHAIN}.mk / mk.paths.${_HOST_OS}.mk pattern rather than an unconditional glob of the directory. When multiple levels each have a matching file, ALL are included (not most-specific-wins), in workspace -> framework -> module order -- simpler than an override rule, and consistent with CFLAGS += style accumulation rather than full replacement
