# From each build host, the test harness must exercise building for every first-class cross-compile target with every applicable toolchain -- not just the hosts own native target

Extends test coverage to the full first-class target matrix (macOS-aarch64, Linux-amd64/arm64, FreeBSD-amd64, Windows-amd64 tiered) -- from any given build host, the harness must test not only building for that hosts own native OS/arch, but cross-compiling for every other first-class target, using every toolchain applicable to that target. This directly exercises mk.toolchain.<name>.mk's cross-compiler path resolution for every (host, target, toolchain) combination actually intended to be supported.
