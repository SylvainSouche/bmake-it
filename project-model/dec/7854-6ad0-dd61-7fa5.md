# The IMPORT=pkg: resolution cache stores only a successful resolution. A 'not found' is never cached, and an existing cache recording one (written by an earlier version) is ignored and removed, so installing the missing package is picked up by the very next build. Re-probing pkg-config costs one subprocess call on a build that fails anyway.
