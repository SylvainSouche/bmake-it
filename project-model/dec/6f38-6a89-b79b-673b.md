# Language scope: C, C++, and lex/yacc grammars for now; Java/Fortran/IDL/Express out of scope

User confirmed scope: C, C++, and lex/yacc grammar files (which generate C/C++ source) are supported for now. Real mkmk also supports Fortran, Java, IDL, and Express grammar -- these are explicitly out of scope for this project at this stage, recorded as REQ-supported-languages (a scope-limiting requirement) rather than an NREQ, since the door is left open for later ('for now').
