# clang for the MSVC ABI is selected by TOOLCHAIN=llvm ABI=msvc (target key win-<arch>: both slots at their default; cl.exe's stays win-<arch>-msvc). It reuses the MSVC toolchain's discovery and scripts/msvc-cc-wrapper.sh, with clang-cl as the compiler driver (cl.exe's own syntax) linking through lld-link (-fuse-ld=lld) and lld-link /lib as the archiver, and -fms-compatibility-version set from the toolset found (14.MM -> 19.MM, else clang guesses an older _MSC_VER). Every TOOLCHAIN=msvc branch about the MSVC runtime tests one variable, _BMK_MSVC_ABI, instead.

Not yet: a non-Cygwin host (cross to MSVC needs Microsoft's headers and libraries there, which Bmake It may not ship); MSVC's limits are kept for sanitizers (address only) and OpenMP until clang's own runtime for it is checked.
