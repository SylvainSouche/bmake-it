# A workspace subdirectory is recognized as a framework if it contains a makefile declaring PREREQS= (now mandatory); typical framework structure also includes module (*.m) subdirectories and/or a share/ directory, though the makefile+PREREQS check is the actual discovery signal

Resolves REQ-modules-and-frameworks-auto-discovered-reqs open discrimination-signal follow-up: a workspace-root subdirectory is treated as a framework if it has a file named makefile that declares PREREQS= (now mandatory per REQ-prereqs-mandatory-even-empty-req). build/ is naturally excluded since it contains no such makefile.
