# bmake test for a target the build host cannot run uses a TEST RUNNER: the target is named by TEST_RUNNER.<os>-<arch> (else TEST_RUNNER), set on the command line or in the hook files like every other setting, as ssh:[user@]host[:port], docker:<image>[@<platform>], cmd:<program> or local. The unit of work is the whole tests directory (kyua hands each ATF program a results file, so it cannot be wrapped per test): scripts/cross-test.sh stages it with the libraries and programs it needs, a generated run.sh runs kyua on the target, and the results come back to the usual runs/<RUN_ID>/. A foreign target with no runner is a loud error before anything is built; TEST_RUNNER=local keeps today's behaviour
