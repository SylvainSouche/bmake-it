# Documentation generation uses Doxygen as both parser and renderer for v1 (a later pluggable DOCS_RENDERER=doxygen|sphinx may consume Doxygen's XML for a richer Sphinx-rendered site). Each framework gets its own Doxyfile+run+tag-file, chained in PREREQS= topological order for cross-framework HTML links -- validated by CAA's own mkmancpp tool, which independently uses the identical framework+prerequisite-based linking model. A workspace-level aggregation step generates a comprehensive cross-workspace name index, a framework-listing landing page, and a workspace-wide inheritance-hierarchy view, adopted from mkmancpp's AllNames.htm/main.htm/tree.htm precedent. Default scope is public headers only (fw/include/), matching CAA's own public+protected default with private opt-in

HTML output design is settled; LaTeX/PDF specifics (per-framework vs combined-workspace, given tag-file cross-linking doesn't carry over reliably to PDF) still an open sub-question -- not yet decided.
