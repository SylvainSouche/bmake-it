# Packaging targets populate distrib/KEY by internally invoking make install with DESTDIR set to that directory

User confirmed the exact mechanism left open in REQ-distrib-dir-for-packaging-staging-req: packaging targets (make port, make pkg, ...) internally run the equivalent of make install DESTDIR=distrib/KEY (workspace-level, target-keyed) as their staging step, reusing the install machinery and its DESTDIR/PREFIX convention (REQ-destdir-prefix-confirmed-req) rather than a separate, parallel copy mechanism. The resulting staged tree at distrib/KEY is then what each per-format packaging target builds its actual artifact from.
