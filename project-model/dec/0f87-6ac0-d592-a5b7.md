# A module or framework declares where it is built with ONE list macro per axis, PLATFORMS= and TOOLCHAINS=, set in its own makefile (no OS section, no BUILD=NO in a per-OS file). An entry is [!][-]name: a plain name means 'only these' (other targets skipped quietly), '-name' excludes quietly, and a leading '!' makes the entry loud -- an error instead of a quiet skip -- on any of them: '!name' is 'only these, error elsewhere', '!-name' is 'excluded, error here'. Platform names are an OS or os_arch (underscore, as share/ and local.<os>_<arch>.mk), toolchain names are llvm/gcc/msvc. An optional REASON.<entry>=text explains either outcome. Rejected: ONLY_FOR/NOT_FOR names (borrowed, unrelated to our vocabulary) and a BUILD=NO line in per-OS files (a second file to edit per exclusion)
