# Cross-compilation must work from any supported host to any supported target; a configuration that is genuinely impossible (licensing or technical reason) must be explicitly stated as a documented limit, never a silent gap

Applies at the build-system level, not narrowly to the self-test harness -- the same any-host/any-target completeness guarantee (with documented exceptions) should hold for end-user software built with Bmake It too, once that functional test-declaration feature (still just a deferred note under build-system-self-test-harness-req) gets its own REQ.
