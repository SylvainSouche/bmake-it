# Each workspace, framework, and module may have its own mk/ directory, taken into account for .include resolution with cascading visibility: at workspace level only WS/mk is visible; from within a framework, WS/mk and FW/mk; from within a module, WS/mk, FW/mk, and MOD/mk. WS/mk's own search also extends to every PARENT_WS's mk/ directory, recursively, matching PARENT_WS's existing cascading semantics for framework/header resolution

Use case stated directly by the user: custom per-module/framework/workspace build configuration without modifying Bmake It's own core mk.*.mk files -- e.g. one specific module needing extra CC flags, or its own macros. Resolves the per-workspace-local-mk-override-topic parked earlier this session.
