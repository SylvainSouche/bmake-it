# Bmake It's configuration directory holds a makefile that includes a role file, mk.bmakeit.mk, which defines the administrative targets (list what is present and what is not; fetch, build, delete; check checksums; and similar). That makefile is where every location is set: the cache directory, and any or all other configuration variables naming where things used and needed live (images, sysroots, tool prefixes, ...). There is no separate default location outside it
