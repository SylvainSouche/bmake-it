# Projects are advised to carry a one-line GNUmakefile that refuses GNU make with a readable message

A makefile cannot refuse GNU make itself: GNU's $(error ...) is an invalid line to bmake, and a BSD directive gives GNU make only 'missing separator'. A file named GNUmakefile next to the makefile is read by GNU make (3.81 on macOS, 4.x) in preference to makefile and is never read by bmake. Tested: gmake and macOS make stop with the message, bmake builds. Limits: gmake -f makefile bypasses it; it must sit in every directory a user may run make in. Decided as documented best practice, not as something Bmake It generates or requires.
