# The environment bmake run sets must be INHERITED by the launched program and must not be overridden by an interactive shell's own startup files (.shrc via ENV, ~/.bashrc, ~/.zshrc): those files still run, nothing is suppressed, and the build entries are re-asserted at the front of PATH and the library variable after them. Login shells (.profile is read first) and other shells are documented limits
