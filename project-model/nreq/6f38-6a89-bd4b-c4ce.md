# The system shall not provide a physical-copy prerequisite mode or dedicated mkCopyPreq/mkGetPreq-equivalent commands

Rejected alternative: real mkmk's mkCopyPreq (physically copies prerequisite framework data into the local workspace for isolation/stability) and mkGetPreq (a separate command to establish/update the dynamic search path). Neither has an equivalent in this system -- prerequisite resolution is purely a dynamic search over the workspace's own declared parent list (REQ-workspace-parent-search-order), with no copy mode and no separate setup command.
