# Build system must run on macOS (third-party package-manager toolchain), Linux, and *BSD

Target host platforms for running the build tooling itself: macOS, Linux, and the BSD family (FreeBSD/NetBSD/OpenBSD etc., native bsd make). Windows is not yet mentioned as a *build host* -- open question, see OBS/ASM on Windows scope.

macOS specifically means a third-party package-manager toolchain, never Apple's own Xcode CLT compiler by default -- per macos-toolchain-tiers-req: MacPorts, Homebrew, and pkgsrc/pkgin are tier 1 (fully supported); Nix is tier 2 (supported, lower priority). Apple's own /usr/bin is searched last, only as a fail-loud-beats-no-detection fallback, never preferred (toolchain-detection-prefix-list-authoritative-req). Originally written narrower ("MacPorts toolchain") when only MacPorts had been considered; broadened 2026-09-15 once Homebrew/pkgsrc/Nix support was actually built and verified.
