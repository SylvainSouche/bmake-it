# Build system shall be implemented in BSD make, using bsd.*.mk infrastructure or reprogrammed equivalents

The build system is built on BSD make (not GNU make). Standard bsd.*.mk include files may be used where they fit, or reprogrammed/replaced where they don't. This is a hard technology constraint, not a preference.
