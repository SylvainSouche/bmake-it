# OPEN (deferred by the user until the mingw link works): a mingw-w64 program needs its runtime DLLs beside it or on PATH to run -- imported libraries' DLLs (OpenRider: libcurl-4.dll, libtiff-5.dll from /usr/x86_64-w64-mingw32/sys-root/mingw/bin) and, for C++, libstdc++-6.dll/libgcc_s_seh-1.dll/libwinpthread-1.dll from the same bin/. Bmake It stages import libraries but not these DLLs, and bmake run does not put that bin/ on PATH.
