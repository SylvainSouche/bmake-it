# OpenRider with ABI=mingw on Cygwin: IMPORT=pkg:libcurl resolved through Cygwin's own pkg-config and libcurl.pc (/usr/lib/pkgconfig, the Cygwin library) instead of the mingw one (x86_64-w64-mingw32-pkg-config -> /usr/x86_64-w64-mingw32/sys-root/mingw/lib/pkgconfig), and that wrong success was cached: the cache key (IMPORT, PKG_CONFIG_PATH, extra dirs, TARGET, TARGET_ARCH) covers neither the ABI, the compiler nor which pkg-config ran, and a hit is never re-checked, so an upgraded or removed package is not noticed either. REQUIRES= also asks the host pkg-config. Separately, the resolver's cross branch reads BMK_<TARGET>_SYSROOT, i.e. BMK_WIN_SYSROOT for win, while the mingw sysroot variable is BMK_MINGW_SYSROOT.
