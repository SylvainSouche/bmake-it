# In real mkmk, a framework's prerequisite list lives in a dedicated per-framework special file (an identity-card file), separate from any module build file

Every framework has exactly one identity file, stored in its own subdirectory directly under the framework root. It contains one declarative line per prerequisite framework. This is a distinct mechanism from the per-module build file -- prereqs are a framework-level concern declared in their own special file, not embedded in a general framework-level makefile. CONFLICT with REQ-framework-prereqs, which currently says 'framework's makefile declares a prereqs list' -- that assumed a single framework-level makefile as the home for this data. Needs a decision: dedicated special file (matches real mkmk) vs. folded into a general framework-level makefile (simpler, fewer special filenames).
