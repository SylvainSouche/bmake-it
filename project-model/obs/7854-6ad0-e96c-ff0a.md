# Probed on Cygwin with mingw64-x86_64-gcc-core/-g++ 14.4 installed: x86_64-w64-mingw32-gcc builds a PE32+ exe depending only on KERNEL32/msvcrt, and a DLL with --out-implib import lib. clang --target=x86_64-w64-mingw32 WITH --sysroot=/usr/x86_64-w64-mingw32/sys-root/mingw compiles C but cannot find C++ headers nor libgcc (they live in /usr/lib/gcc/x86_64-w64-mingw32/14); WITHOUT --sysroot clang locates that gcc installation itself and C and C++ both build and link (GNU ld via -fuse-ld=bfd; lld not installed). -dumpmachine spellings: Cygwin clang x86_64-pc-windows-cygnus, Cygwin gcc x86_64-pc-cygwin, clang for mingw x86_64-w64-windows-gnu, mingw gcc x86_64-w64-mingw32. Also: a Cygwin host could not select mingw output for its own arch at all, and the rule-based win ABI label would call a CC=x86_64-w64-mingw32-gcc override 'cygwin'.
