# A percent sign in a workspace, framework or module name stops the link under FreeBSD 15.1's make, and works on macOS, NetBSD and Linux

The compile works; the link fails with 'ld: error: cannot open output file .../build/freebsd-arm64/bin/x: No such file or directory'. The rule that creates build/<key>/bin has the absolute directory in its target, and FreeBSD's make reads % in a target as a pattern. NetBSD 10.2, macOS (bmake 20260406) and Debian/Alpine bmake build it. Same family as = (read as an assignment under macOS/Alpine bmake): the path sits in a dependency line. Fix: relative targets (docs/spec/85-names-and-paths.md). Until then the case lists percent with equals as a mixed-platform gap.
