# A cross-compile sysroot holds the target OS only, so a cross build with prerequisites cannot work yet, for two separate reasons. (1) Lookup: only mingw-w64 has its own pkg-config (pkg-config-matches-output-abi-req); for linux, freebsd, netbsd and macos targets IMPORT=pkg: and REQUIRES= run the BUILD HOST's pkg-config, so a library the OS itself ships (FreeBSD's base has zlib.h and libz.so but no zlib.pc) is reported not found, and one the host happens to have returns the host's flags for the wrong ABI. (2) Content: vm.sh sysroot tars only usr/include, usr/lib and lib, so FreeBSD's /usr/local and NetBSD's /usr/pkg (where every non-base library lives) are absent, and the Linux sysroot is libc6-dev plus gcc runtime only; cJSON, SDL and the like are nowhere in any sysroot
