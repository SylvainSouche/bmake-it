# An unrecognized cross-compile TARGET compiled with zero cross flags and no warning, silently producing a host-native binary while claiming to target something else

mk.toolchain.llvm.mk's cross-compile branch chain (.if TARGET==freebsd .elif ...linux ...macos) had no final .else. TARGET=netbsd (before that branch existed) -- or any typo, or a future target name not yet added -- set BMK_IS_NATIVE_BUILD=no, matched none of the branches, left _CROSS_FLAGS undefined, and fell through to compiling with the plain native CC and no cross flags at all: a host-native binary written into build/<claimed-target>/, indistinguishable by directory name from a genuinely cross-compiled one. This is the exact failure class REQ-toolchain-mk-must-set-explicit-cc-paths-req-v5 was written to prevent for host-native compiler lookup (never silently substitute) -- it just wasn't closed for this second, separate lookup (the cross-target branch selection itself).
