# Building OpenRider with ABI=mingw on Cygwin: (1) the LIBS= link-time check (mk.lib.mk and mk.prog.mk) accepts lib<n>.a/.so/.dylib and <n>.lib but not mingw's DLL import library lib<n>.dll.a (e.g. libcurl.dll.a, staged by IMPORT=pkg:), so it reports 'not built yet' for a library GNU ld/lld would find; the same name list is copied into the relink-prerequisite lookups and IMPORT= probing, and the shared-vs-static choice for an IMPORT=pkg: library looks only for .so/.dylib, so a mingw DLL import would take pkg-config's --static closure. (2) clang's mingw driver does not link winpthread while Cygwin's mingw gcc always does (its specs: %{!no-pthread:-lpthread}): clang fails on pthread_create (C) and std::mutex (C++), both link with -pthread.
