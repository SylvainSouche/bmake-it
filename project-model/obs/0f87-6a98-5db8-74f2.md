# The cross-compile sysroot requirement check fired even for a bare -V query or a clean, neither of which ever invokes a compiler

The sysroot-requirement .error in mk.toolchain.llvm.mk's cross-compile branch chain runs unconditionally at parse time, evaluated whenever BMK_IS_NATIVE_BUILD==no -- with no distinction between an invocation that will actually compile something and one that only wants a computed macro value (like OS_ARCH, used by the target-key naming tests) or a clean. A previously-passing test (23-linux-target-key) broke the moment cross-compilation support was added, purely because the query now touched a TARGET/TARGET_ARCH combination that looked like a cross build to the check, despite never approaching a compile step.
