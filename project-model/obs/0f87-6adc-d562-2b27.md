# Beyond cross-sysroot-os-only-obs: a cross build to another architecture of the same OS (linux-amd64 from linux-arm64) was not treated as cross by the IMPORT=pkg: resolver, which tested TARGET only, and staged the host's aarch64 libcurl and libtiff (ld.lld: incompatible with elf64-x86-64); the resolution cache key did not cover the pkg-config environment, so an answer made with another sysroot was reused; the harness's Linux sysroot lacked usr/lib/linux (Debian 13's uapi headers, which usr/include/<multiarch>/asm links into) and the image's -dev packages. Running the tests with TEST_RUNNER=local under Docker's qemu-user failed until QEMU_LD_PREFIX pointed the emulator at the sysroot
