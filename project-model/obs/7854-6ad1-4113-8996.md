# OpenRider with ABI=mingw (TOOLCHAIN=llvm) on Cygwin: tile_fetcher.cpp failed to link with undefined std::__once_callable and std::__once_call. clang links the libstdc++ that comes with mingw-w64 gcc, which gcc builds with emulated TLS, so its thread-locals exist only as __emutls_v._ZSt15__once_callable etc.; clang emits native TLS references by default. Reproduced with a five-line std::call_once program: fails as built, links and runs with -femulated-tls. An llvm-mingw sysroot ships its own native-TLS C++ library and must not get the flag.
