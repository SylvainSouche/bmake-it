# NetBSD's ftp(1) cannot fetch a file:// URL: 'ftp: ftp_strdup: called with NULL argument', an empty output file and a zero status, so the system-downloader fallback silently produced nothing for a local mirror. It does fetch http and https (verified on 10.2) and reports a missing URL with status 1. The matrix hid it because the provisioned BSD guests carry curl as a dependency of cmake, so the fallback was never exercised there
