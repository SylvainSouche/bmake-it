# Every framework makefile must declare PREREQS= explicitly, even with no value, e.g. PREREQS= for a framework with no prerequisites

Strengthens REQ-framework-prereqs-macro-req: PREREQS= is mandatory in every framework makefile, not merely present-if-needed. An empty declaration (PREREQS= with nothing after it) is valid and means the framework has no prerequisites. Serves double duty as the discovery signal for REQ-framework-discovery-signal-req.
