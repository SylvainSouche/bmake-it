# MacPorts layer of the macOS harness VM installs: bmake, llvm (clang/lld), gcc, docker, colima, lima, tart -- a complete toolchain+container+VM stack from one package manager, no Homebrew needed

docker (CLI-only per its own port description) + colima (daemon, built on lima, uses macOS Virtualization.framework -- hvf-accelerated, not QEMU) together give a complete Docker stack for the harness's Linux/Docker matrix rows. tart covers the separate macos-VM-under-VM leg. Concrete list is specific to the MacPorts layer; the equivalent Homebrew/pkgsrc-pkgin/Nix layers still need their own package-name verification, not assumed to mirror this one 1:1.
