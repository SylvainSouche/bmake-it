# REQUIRES=header:<path> checks a header is reachable on the compiler's search path, as the deferred half of header-only-import-req's proposal

REQUIRES entries matching the prefix 'header:' (split on first ':') are checked by preprocessing a trivial translation unit that #includes the given path, using CC and CFLAGS as defined at the point REQUIRES= is evaluated (before mk.local.mk's own CFLAGS+= hooks run) -- -E/-x c is used unconditionally, since the preprocessor does not parse C++ body syntax and so accepts a C++-only header (templates, namespaces) the same as a plain C one; this avoids any C-vs-C++ dispatch. A missing header is a parse-time .error, matching REQUIRES='s existing failure style. This is the header-path-check half of header-only-import-req's original two-part proposal; the IMPORT_LIB=none half was already implemented separately.
