# IMPORT=pkg:<name> resolution is fingerprint-cached per module, for a successful resolution only. The key covers IMPORT=, PKG_CONFIG_PATH, _PKG_CONFIG_EXTRA_DIRS, TARGET/TARGET_ARCH, OS_ARCH (so ABI and toolchain), CC and the pkg-config used; an unchanged key does not re-invoke pkg-config, a changed one does. A cached hit also records the resolved .pc file and its mtime, and is discarded when that file no longer exists or its mtime differs (checked with bmake's :mtime, no subprocess), so an upgraded or removed package is re-resolved. A 'not found' is never cached.
