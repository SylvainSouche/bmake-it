# A progressive-complexity Qt test harness verifies the mechanism level by level, each level headless/CI-runnable (no real display server required): Level 0 -- QtCore-only console app (QCoreApplication, QString, qDebug()), zero code generation, proves module discovery/link only; Level 1 -- adds a QObject-derived class with a signal/slot connected in a QCoreApplication event loop, proves MOC discovery+generation+link, still headless; Level 2 -- a QWidget+.ui-driven app run under QT_QPA_PLATFORM=offscreen (Qt's own supported headless platform plugin), proves UIC; Level 3 -- adds an embedded .qrc resource (e.g. an icon), proves RCC. QML/Qt Quick is out of scope for this initial harness -- a further, separate level if ever needed
