# A guest's packages come from BMK_CACHE, like its image: the first provisioning keeps the package files the guest downloads under BMK_CACHE/packages/<os>-<version>-<arch>/ (with MANIFEST.sha256), and every later layer build installs them from there with no network -- so rebuilding a layer, or building it on another host, neither depends on DNS, mirrors or connectivity nor silently changes the versions tested
