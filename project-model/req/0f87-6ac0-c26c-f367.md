# Header staging for an IMPORT= resolved by pkg-config also searches the package's includedir (pkg-config --variable=includedir) after any -I from --cflags: pkg-config omits -I<dir> for a system directory such as /usr/include, so a Linux import of glm or glfw3 had no include directory to stage from. Only staging gains the directory; the compile flags are unchanged
