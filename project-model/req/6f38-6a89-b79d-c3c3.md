# The build system supports C, C++, and lex/yacc grammar sources (compiled to C/C++); other mkmk-supported languages (Java, Fortran, IDL, Express) are out of scope for now

Supported source languages: C, C++, lex, and yacc (lex/yacc are grammar sources that generate C or C++ source, matching the .l/.lc/.y/.yc suffix convention seen in the mkmk reference docs). Java, Fortran, IDL, and Express grammar -- all supported by real mkmk -- are out of scope for now. This scopes down REQ-module-src-auto-discovery and REQ-module-makefile-fields (compiler/ object-type selection only needs to cover these languages) and means Java-specific mechanisms noted in OBS-mkmk-java-and-windows-specifics do not need to be designed for at this stage.
