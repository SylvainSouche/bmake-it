# A module makefile may include mk.common.mk first, without BMK_MKDIR being set

mk.common.mk sets BMK_MKDIR to its own directory when it is not defined, so '.include "mk.common.mk"' as the first line of a module makefile works whether run directly or from its workspace; TARGET, TARGET_ARCH and _TARGET_KEY (TOOLCHAIN-suffixed) are then readable before .include of the role file. The role file's own later include of mk.common.mk is a no-op (include guard).
