# mk.prog.mk/mk.lib.mk must link a module with ${CXX} when its SRCS contain a C++ source or LINK_CXX=yes is set, and with ${CC} otherwise

Applies identically to mk.prog.mk's executable link recipe and mk.lib.mk's shared-library link recipe (SHLIB_LD-equivalent). LINK_CXX=yes forces ${CXX} regardless of SRCS -- the override for a C-sources-only module linking a static C++ library. Detection uses the three C++ extensions mk.prog.mk/mk.lib.mk already compile as C++ (cc, cpp, cxx), not sys.mk's own CXX_SUFFIXES (which additionally includes .C, out of scope here).
