# The rules of a module build name their targets and prerequisites relative to the module directory

A module build always runs in the module directory, so the objects, the program or library, the inputs-hash file, the sources and the test binary are named relative to it in every dependency line (build/<key>/obj/x.o: src/x.c), and the compiler is given the same relative names (-c src/x.c -o build/<key>/obj/x.o) so the .d file it writes names a relative target. No character of the directory's path then sits in a target or prerequisite, where make reads = as an assignment (macOS and Alpine bmake), % as a pattern (FreeBSD 15.1 make), * ? [ as wildcards and : ! # as syntax. Recipes may still use absolute paths as shell arguments.
