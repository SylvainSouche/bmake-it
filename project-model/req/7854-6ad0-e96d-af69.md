# For TARGET=win the ABI slot of the target key is read from the compiler actually used: msvc for TOOLCHAIN=msvc (omitted from the key as the win default); otherwise CC -dumpmachine, *cygwin*/*cygnus* -> cygwin, *mingw32*/*windows-gnu* -> mingw, *windows-msvc* -> msvc. An unrecognized answer is an error naming it (a -V query falls back to the toolchain/host rule instead). ABI= given explicitly must match, or the build fails naming both, the toolchain and the compiler's answer.
