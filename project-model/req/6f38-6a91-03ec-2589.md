# make automatically regenerates the order cache (running the equivalent of make order) if it is missing or stale, before proceeding with the build; make order remains separately invocable on its own

The order cache (REQ-order-target-blank-run-req) is treated as an implicit prerequisite of the default build target, not an optional manual step: if the cache does not exist or is detected stale (exact staleness-detection mechanism still deferred per OBS-cache-mechanism-needs-empirical-check, same as the other bsd.depend-style caches), make regenerates it automatically before proceeding, so a fresh checkout builds correctly with plain make and no mandatory separate invocation. make order remains available as its own standalone target for developers who want to inspect the resolved build order without triggering a build.
