# When PROG= or LIB= is not set in a module's makefile, it defaults to the module's directory name with the .m suffix stripped

Refines REQ-module-prog-or-lib-macro-req and REQ-module-dir-naming-convention: a module directory named NAME.m defaults to PROG=NAME (if .include <mk.prog.mk>) or LIB=NAME (if .include <mk.lib.mk>) when the corresponding macro is left unset in the module's makefile.
