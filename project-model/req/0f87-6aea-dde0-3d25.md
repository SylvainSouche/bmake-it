# A parse-time setting changed after mk.common.mk ran stops the build with an error

After the pre-phase hooks, mk.prog.mk, mk.lib.mk, mk.tst.mk, mk.framework.mk and mk.workspace.mk compare TOOLCHAIN, ABI, TARGET, TARGET_ARCH, OPENMP and SANITIZE with the values mk.common.mk resolved. A difference is a .error naming the variable, both values, and the two ways out: set it before the .include of mk.common.mk, on the command line or in the environment. Setting the same value again is accepted. Applies to the module body after an early include and to mk/pre*.mk hooks.
