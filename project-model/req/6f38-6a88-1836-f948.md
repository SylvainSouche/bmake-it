# A framework's makefile declares a prereqs list of other frameworks it depends on; prereq headers are accessible when building, and generated binaries can be linked against prereqs

Framework-level makefile defines `prereqs`: a list of frameworks that this framework uses. Effect: while building this framework, the public headers (include directory) of every listed prereq framework are accessible, and binaries generated by this framework may be linked against binaries generated by the prereq frameworks.
