# For TARGET=win the ABI slot of the target key is derived, never assumed: msvc for TOOLCHAIN=msvc (omitted from the key as the win default), cygwin for any other toolchain building natively on a Cygwin host (win-amd64-cygwin, win-amd64-gcc-cygwin), mingw for any other toolchain cross-compiling (win-amd64-mingw, win-arm64-mingw). ABI= given explicitly must match the derived value, or the build fails naming both and the toolchain.
