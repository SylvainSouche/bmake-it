# On a Cygwin host, ABI=mingw with TOOLCHAIN=gcc or llvm builds mingw-w64 output for the host's own arch (key win-<arch>[-gcc]-mingw): gcc uses <triple>-gcc/-g++/-ar/-ranlib; llvm uses clang --target=<triple> (--sysroot only from BMK_MINGW_SYSROOT), -fuse-ld=lld if ld.lld is installed, else -fuse-ld=bfd with mingw's binutils. A missing mingw compiler or binutils is an error naming the Cygwin packages that provide them.
