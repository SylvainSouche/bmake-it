# A workspace's makefile declares PARENT_WS=<path1> <path2> ... , an ordered, space-delimited list of ABSOLUTE paths to parent workspace roots; relative paths are not used

Refines REQ-workspace-parent-search-order and REQ-uniform-makefile-filename-req with the concrete macro: PARENT_WS=<abs-path-1> <abs-path-2> ... in the workspace's makefile, preserving declaration order for the fallback search. Only absolute paths are supported -- relative paths were explicitly considered and rejected as too fragile/confusing.
