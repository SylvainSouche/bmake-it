# The workspace-level build proceeds in order: resolve PARENT_WS, resolve each frameworks PREREQS (headers), build each module (compile-then-link-then-copy-up to framework), copy framework outputs up to workspace, with share/ resources following the same module-to-framework-to-workspace cascade

Consolidated build sequence, ties together REQ-workspace-parent-macro-absolute-req, REQ-framework-prereqs-macro-req, REQ-headers-resolved-from-source-req, REQ-generated-headers-in-build-tree-req, REQ-prereqs-misorder-no-validation-req, REQ-module-prog-or-lib-macro-req, REQ-module-level-build-subdirs-req, REQ-aggregation-step-copies-outputs, and REQ-share-overlay-copy-order into one ordered flow: (1) resolve PARENT_WS; (2) resolve each frameworks PREREQS for header search paths (no cycle/order validation); (3) per module: compile src/ to obj/, link to the modules own bin/ or lib/, copy the linked artifact up to the frameworks bin/lib/; (4) copy framework bin/lib/ up to workspace bin/lib/; (5) resources (share/) cascade the same way, module to framework to workspace, each level applying its own common/os/os_arch overlay before copy-up.
