# An unsupported character in a workspace, framework, module or install-directory name is refused before any build step, with an explanation

Before any build step -- clean, help and -V queries included, because an unquoted rm -rf of a path with a space can remove the wrong directory -- mk.common.mk checks the directory being built (every component of it) and the mk directory, and the order scripts check each framework and module name they discover. A refused name stops the build with one message: the path, the component, the character in words ('a space', 'a colon'), why (the shell or make reads it as syntax, or 'not supported yet'), and the characters that do work. Refused in names: tab, backslash, double quote, backquote, dollar sign, semicolon, vertical bar, less-than, greater-than, asterisk, question mark, exclamation mark, colon, comma, newline; braces in module names. Refused in the mk directory name: tab, backslash, double quote, backquote, dollar sign, semicolon, vertical bar, less-than, greater-than, newline. Not supported yet (until fixed): space, parentheses, apostrophe, ampersand, hash. Never a silent success.
