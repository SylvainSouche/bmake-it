# A module's makefile.mk declares libraries to link with, the object type (static lib / shared lib / executable), and may provide additional compile or link options

makefile.mk (module-level) is the source of truth for: the libraries the module links against, the object type it produces (static lib, shared lib, or executable), and any additional compiler or linker options beyond build-system defaults.
