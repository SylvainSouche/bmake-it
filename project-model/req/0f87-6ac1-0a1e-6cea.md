# bmake test is preceded by a build of everything it can reach, in build order: at workspace scope the whole workspace (all, then test); at framework scope the PREREQS= closure found in the same workspace (depth first, cycle-guarded) and the framework's own modules. A framework without tests is therefore never skipped just because it has none -- its imported headers and libraries are staged. A build failure stops test with that failure
