# glibc is the default libc for Linux targets and is omitted from the target key; musl is always shown explicitly (e.g. linux-arm64-musl)

Resolves the libc-default follow-up from OBS-linux-libc-choice-parallels-win-abi, applying the general omit-if-default convention (REQ-target-key-omit-defaults-req) to Linux: glibc is the implicit default, so linux-<arch>[-<toolchain-if-non-default>] alone means a glibc build. musl must always be spelled out explicitly as an additional suffix. Still deferred, unaffected by this: Linux is not in REQ-phase1-concrete-targets, and per-distro Linux labeling remains an open follow-up per REQ-os-label-set-req.
