# A framework makefile may set DOC_INPUT_EXTRA= (framework-relative directories, e.g. local/include openrider.m/src) to add headers to its Doxygen INPUT, DOC_WARN_IF_UNDOCUMENTED= to have Doxygen report undocumented entities, and DOC_EXTRACT_PRIVATE= to include private members; all default to the previous behaviour. A framework with no public include/ but a non-empty DOC_INPUT_EXTRA is documented rather than skipped
