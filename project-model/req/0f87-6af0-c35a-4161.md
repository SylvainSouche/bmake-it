# No path in a dependency line carries a space or a parenthesis

Spec-grade: make cannot write either in a prerequisite (a space ends the word, a parenthesis is an archive member). The paths a rule, the compiler dependency file and a relink name are relative to the module directory, so no part of the workspace path is in them; a prerequisite framework whose name or place has one is reached through build/<key>/prereqs/<encoded name>. An ampersand, an apostrophe and a hash sign are written as they are.
