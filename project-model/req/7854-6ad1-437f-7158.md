# bmake run for mingw-w64 output (ABI=mingw on Cygwin, or a mingw cross build run on Windows) puts the mingw-w64 runtime bin/ on PATH after the workspace's own lib/bin chains, so a program needing libstdc++-6.dll, libgcc_s_seh-1.dll, libwinpthread-1.dll or a mingw package's DLL from that bin/ starts; and run invoked from a framework or module directory keeps ABI= when it re-executes at the workspace root.
