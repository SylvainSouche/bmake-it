# PLATFORMS= and TOOLCHAINS= take a space-separated list whose entries are [!][-]name (default: every platform/toolchain). Platform names match an OS (macos) or one architecture of it (macos_arm64, underscore as in share/ and local hooks); an OS entry matches every architecture. Toolchain names are those of mk.toolchain.<name>.mk (llvm, gcc, msvc). A plain name is a positive entry (only these), '-name' a negative entry (not these), '!' a loud modifier valid on both
