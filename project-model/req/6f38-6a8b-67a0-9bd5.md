# TOOLCHAIN=<gcc|llvm> selects and .includes a dedicated toolchain mk file (mk.toolchain.<name>.mk) that sets CC/CXX/LD/AR/AS and related tool choices for that toolchain; these remain individually overridable via normal make variable precedence

Completes REQ-toolchain-cli-variable-req with the concrete mechanism: setting TOOLCHAIN=gcc or TOOLCHAIN=llvm causes the build infrastructure to .include a matching mk.toolchain.<name>.mk file, which sets the underlying tool variables (CC, CXX, LD, AR, AS, and any other tool-chain-specific settings) as a coherent bundle for that toolchain. This follows the same role-specific-include pattern already used for workspace/framework/module makefiles (REQ-uniform-makefile-filename-req). Individual variables (CC=, LD=, etc.) remain overridable afterward via ordinary make variable-precedence rules, for mixed setups (e.g. clang with GNU ld) -- exact mk.toolchain.<name>.mk contents and file-naming scheme not yet fully specified, open follow-up for the implementation phase.
