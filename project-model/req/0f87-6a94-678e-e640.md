# A module's makefile declares either PROG=<name> (executable, via .include <mk.prog.mk>) or LIB=<name> (library, via .include <mk.lib.mk>)

Restates the part of REQ-module-build-macros-req that survived its later corrections unchanged: the module-level macro selecting executable-vs-library output. PROG=<name> selects an executable build (.include <mk.prog.mk>). LIB=<name> selects a library build (.include <mk.lib.mk>); whether the result is shared or static is controlled by LIB_SHARED=YES|NO, per REQ-lib-shared-is-new-not-reused-req. Linking against other libraries is controlled separately by LIBS=, per REQ-libs-macro-link-only-headers-via-prereqs-req, which superseded this REQ's original LINK_WITH= design. Default naming when PROG=/LIB= is left unset is covered by REQ-prog-lib-default-to-module-name-req.
