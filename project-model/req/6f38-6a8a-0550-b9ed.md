# Each native packaging format has its own named make target (e.g. make port, make pkg, ...); there is no single generic 'make package' target that takes a format parameter

Refines REQ-packaging-native-formats-separate-target: the packaging mechanism is one make target per format, not a unified target with a format argument. Confirmed target names so far: port (BSD ports-style package) and pkg (macOS-style package). Full mapping of target name to OS/format for every combination in REQ-os-label-set-req is still open (e.g. deb/rpm target names for Linux, msi handling for win/Cygwin-WSL).
