# Module discovery treats a *.m/*.tst directory that has no makefile and contains only build output (build, distrib, work, distfiles, .depend, .gen-*.mk) as a leftover: it is not built, a warning names it and says bmake clean removes it, and the build goes on; the framework's bmake clean removes such leftovers (any target scope). A *.m without a makefile that contains anything else still fails order generation, naming what it contains, and clean leaves it untouched with a warning.
