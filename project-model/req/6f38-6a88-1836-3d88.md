# Building a module generates an obj directory containing an OS_ARCH subdirectory; build output is placed there

During build, an `obj` directory is created under the module, and underneath it an `OS_ARCH`-named subdirectory (host-specific, e.g. something like linux-x86_64, macosx-arm64 -- exact naming scheme still open). Build results (object files, and presumably the final linked artifact) are written there.
