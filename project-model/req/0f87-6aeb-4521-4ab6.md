# The documentation presents the GNUmakefile stub as the best practice for refusing GNU make

The README (Using Bmake It in your own project), the CLI reference and bmake-it(7) show the stub, say why it must be a separate file, and state its limits (gmake -f makefile bypasses it; one per directory run from). Documentation only: Bmake It does not create the file.
