# run sets the build environment and executes PROGRAM through it: PATH = workspace bin then each PARENT_WS bin then the caller's PATH; the library search variable (DYLD_LIBRARY_PATH macOS, LD_LIBRARY_PATH elsewhere, PATH on Windows) = workspace lib then each PARENT_WS lib then its previous value (no trailing empty entry); BMK_BINDIR, BMK_LIBDIR and BMK_SHAREDIR = the colon-separated bin, lib and share chains; BMK_TARGET = the target key. A PROGRAM found nowhere on that PATH is an error naming the chain and saying to build first -- run itself does not build. stdin and stdout pass through (a non-zero exit status of the program fails the make and is reported as its error code), so PROGRAM=sh is an interactive subshell
