# TOOLCHAIN=msvc works from a mounted EWDK with no Visual Studio installed: with BMK_EWDK_ROOT set, mk.vcvarsall.mk derives the MSVC toolset (VC/Auxiliary/Build/Microsoft.VCToolsVersion.default.txt under <root>/Program Files/Microsoft Visual Studio/<ver>/BuildTools) and the Windows SDK (<root>/Program Files/Windows Kits/10) from it, without vswhere; anything missing there is an error naming the path. The SDK version chosen is the highest 10.* directory under Include.
