# Headers have three visibility levels: framework/include (public, to prereq-declaring frameworks), framework/local/include (to the frameworks own modules), and module.m/include (to that modules own sources only)

Supersedes REQ-framework-header-exposure. Three header directories, each with a distinct audience: framework/include/ headers are visible to any other framework that declares this one as a prereq (via PREREQS=, see REQ-framework-prereqs-macro); framework/local/include/ headers are visible to all modules within this framework but not to other frameworks; module.m/include/ headers are visible only to that modules own source files, not even to sibling modules in the same framework. No cross-level include-direction enforcement (e.g. public cannot include local) has been decided yet -- open follow-up, lower priority.
