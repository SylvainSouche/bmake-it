# A module makefile declares INCL=<header1> <header2> ... to name which of its generated headers are promoted to public (copied up to the framework build/<KEY>/include/ on module build); unlisted generated headers remain module-private

Closes the open declaration-macro follow-up on REQ-generated-headers-in-build-tree-req. INCL=<header1> <header2> ... in a module makefile (mk.prog.mk or mk.lib.mk context) lists, by filename, which of that modules generated headers should be promoted to public. On module build, exactly those files are copied from module/build/<KEY>/include/ up into framework/build/<KEY>/include/ (the generated-only framework-level directory, per REQ-generated-headers-in-build-tree-req). Any generated header not named in INCL= stays private to the module.
