# With a sysroot-aware pkg-config, a package whose .pc file lies outside the sysroot (reported pcfiledir does not exist, the unprefixed one does) is queried with PKG_CONFIG_SYSROOT_DIR empty, so its paths are its own; packages inside the sysroot keep the prefix.
