# make add-prereq FW=<name> appends <name> to the current frameworks PREREQS=; make add-parent WS=<abs-path> appends <abs-path> to the workspaces PARENT_WS=; both edit the makefile text directly rather than requiring hand-editing

Two convenience targets: add-prereq (run within a framework directory, argument FW=<name>, appends <name> to that frameworks PREREQS= line, preserving existing order per REQ-framework-prereqs-macro-req) and add-parent (run at workspace root, argument WS=<absolute-path>, appends the path to PARENT_WS= per REQ-workspace-parent-macro-absolute-req -- absolute paths only, consistent with that REQ). Both are pure text-editing convenience over the makefile, not search-path resolution or copying -- explicitly does not reopen or contradict NREQ-no-copy-preq-commands. Exact edit mechanism (sed-style in-place edit vs. parse-and-rewrite) not yet specified, open follow-up for implementation.
