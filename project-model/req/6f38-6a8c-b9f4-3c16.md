# A module supplies additional compile or link options by appending directly to bsd makes own native CFLAGS/CXXFLAGS/LDFLAGS/YFLAGS/LFLAGS variables in its makefile (e.g. CFLAGS+=-DFOO); no project-specific LOCAL_*FLAGS wrapper macros exist

Closes REQ-module-makefile-fields original additional compilation or link options provision with a concrete mechanism: standard bsd make variables (CFLAGS, CXXFLAGS, LDFLAGS, YFLAGS, LFLAGS for the in-scope languages per REQ-supported-languages) are used unchanged, extended via ordinary += in a module makefile. This is consistent with the projects general principle of reusing bsd-make-native variables wherever they already exist, applied identically to how TARGET=/TARGET_ARCH=, DESTDIR/PREFIX, and DEBUG_FLAGS/optimization flags were handled.
